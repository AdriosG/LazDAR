
# LazDAR Viewer

Renders hillshade and MNS view of LAS/LAZ files.


## Installation

Install requirements :

```bash
python -m pip install numpy laspy PySide6 pyqtgraph

```

Run the Script:

```bash
python lazdar.py
```


## FAQ

#### How to change the view or the view parameters?

Use the left hand panel to tweak the settings and switch views (Hillshade/MNS)

#### What is the Step parameter?

The step is the resolution, it allows the program to render every point separated by the step value.
